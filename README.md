# 원스텝캡쳐

광고, 로그인, 계정, 사용 정보 수집이 전혀 없는 Windows 화면 캡처 도구입니다.

## 받는 곳

**[최신 판 다운로드](https://github.com/Gobong-Choi/onestepcapture/releases/latest)**

이 주소는 바뀌지 않습니다. 새 판이 나와도 같은 주소에서 받으실 수 있습니다.

## 설치

1. ZIP 파일을 받아 **압축을 풉니다** (ZIP 안에서 바로 실행하면 동작하지 않습니다)
2. 풀린 폴더의 `설치.cmd` 를 실행합니다
3. 관리자 권한은 필요하지 않습니다

## 주요 기능

| 기능 | 기본 단축키 |
|---|---|
| 영역 캡처 | Alt + 1 |
| 전체 화면 캡처 | Alt + 2 |
| 활성 창 캡처 | Alt + 3 |
| 스크롤 캡처 (긴 페이지를 한 장으로) | Alt + 4 |

편집기에서 펜·형광펜·사각형·화살표·모자이크·글자를 넣을 수 있고, 확대/축소와
캡처 기록 관리를 지원합니다. 트레이에 상주하며 유휴 시 메모리 1MB 미만입니다.

## 인터넷 접속에 대하여

인터넷에 접속하는 곳은 **설정 창 `정보` 탭의 `업데이트 확인` 버튼 하나**뿐입니다.
누르지 않으면 아무것도 주고받지 않으며, 누를 때도 최신 판 번호만 확인합니다.
사용 정보나 개인정보는 어디에도 보내지 않습니다.

## 왜 exe 가 아닌가

Windows Smart App Control 이 서명되지 않은 `.exe` 를 차단하기 때문에,
Microsoft 가 서명한 PowerShell 을 통해 소스를 메모리에서 컴파일해 실행합니다.
그래서 **프로그램 소스(`원스텝캡쳐.cs`)가 배포본 안에 평문으로 들어 있고,
메모장으로 열어 무엇을 하는지 직접 확인하실 수 있습니다.**
