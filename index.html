Windows 화면 캡처 도구

v1.9.5 · 약 74KB · Windows 10 / 11
이전 판·변경 내용 보기

설치

  1. 받은 ZIP 파일을 오른쪽 클릭 → 압축 풀기
    압축 안에서 바로 실행하면 아무 일도 일어나지 않습니다.
  2. 풀린 폴더의 설치.cmd 실행
  3. 끝. 관리자 권한이 필요하지 않습니다.

설치가 끝나면 압축을 푼 폴더는 지워도 됩니다. 창 없이 트레이에서 조용히 실행되며 단축키가 바로 동작합니다.

단축키

Alt + 1영역 캡처 — 드래그로 범위 선택
Alt + 2전체 화면 캡처 — 다중 모니터 포함
Alt + 3활성 창 캡처
Alt + 4스크롤 캡처 — 긴 페이지를 한 장으로

설정 창에서 원하는 키로 바꿀 수 있습니다.

기능

  • 편집 — 펜, 형광펜, 사각형, 화살표, 모자이크, 글자. 써둔 글자는 끌어서 옮길 수 있습니다.
  • 확대 / 축소 — Ctrl + 마우스 휠. 10%~800%.
  • 스크롤 캡처 — 영역을 지정하면 자동으로 스크롤하며 이어 붙입니다. 위·아래 양방향.
  • 캡처 기록 — 썸네일 목록에서 클릭 한 번으로 전환, 여러 개 선택해 한 번에 저장.
  • 가벼움 — 트레이에 있을 때 메모리 1MB 미만.

백신이 경고할 수 있습니다

Windows 보안 기능(Smart App Control)이 서명되지 않은 .exe를 차단하기 때문에, Microsoft가 서명한 PowerShell을 통해 실행되는 형태로 배포됩니다. 이 방식 자체를 백신이 의심스럽게 보는 경우가 있습니다.

대신 프로그램 소스가 배포본 안에 평문으로 들어 있습니다. 원스텝캡쳐.cs와 설치.cmd를 메모장으로 열어 무엇을 하는지 직접 확인하실 수 있습니다. 숨기거나 암호화한 부분은 없습니다.

받은 파일이 진짜인지 확인하려면

ZIP 파일이 있는 폴더에서 명령 프롬프트를 열고:

certutil -hashfile OneStepCapture-Setup.zip SHA256

나온 값이 아래와 같아야 합니다.

0B09D673E61066092E6DC84ACF693CE19AE2DCB05FB8F4603F9ABEE685CC43B6

판이 바뀌면 이 값도 바뀝니다. (현재 v1.9.5 기준)

인터넷 접속에 대하여

인터넷에 접속하는 곳은 설정 창 [정보] 탭의 [업데이트 확인] 버튼 하나뿐입니다. 누르지 않으면 아무것도 주고받지 않고, 누를 때도 최신 판 번호만 확인합니다.

사용 정보나 개인정보는 어디에도 보내지 않습니다. 광고, 로그인, 계정, 자동 업데이트가 없습니다.
