v1.9.7 2026-08-14 지금 판

  • 편집 창 아래에 후원 표기 한 줄이 생겼습니다. 전국 당일 꽃배달 서비스 「꽃집청년들」이 이 프로그램을 지원합니다. 주소를 누르면 브라우저로 열립니다. 광고는 그 한 줄이 전부입니다 — 팝업·배너가 없고, 프로그램이 광고를 받아오지도 않습니다. 그래서 안내 페이지의 「광고 없음」 표현도 사실에 맞게 전부 고쳤습니다.
  • 설정 창 안내를 읽기 쉽게 고쳤습니다. 그동안 설명이 전부 항목 이름 뒤 괄호에 들어가 한 줄이 길었고, 이름과 설명이 같은 색·같은 크기라 눈에 안 들어왔습니다. 이제 이름은 밝게, 설명은 그 아래 줄에 놓입니다.
  • 캡처 기록이 비어 있을 때 안내가 나옵니다. 예전에는 빈 상자만 있었습니다. 지금 설정된 단축키를 그대로 알려주므로, 키를 바꾸셨어도 맞는 안내가 나옵니다.
  • 단축키 탭에서 지금 할 일이 먼저 보이고, F1~F12 · Print Screen 같은 예외 설명은 그 아래로 내려갔습니다.
  • [정보] 탭 설명이 문장 중간에서 줄이 끊기던 것을 고쳤습니다.

v1.9.6 2026-08-14

  • 창을 좁히면 편집 창 도구모음 오른쪽이 잘려 누를 수 없던 문제를 고쳤습니다. 창을 최대화하지 않으면 [다시 캡처: 영역 · 전체 화면 · 활성 창 · 스크롤] 중 뒤쪽이 화면 밖으로 밀려났습니다. 이제 자리가 모자라면 글자부터 차례로 빠지고 아이콘만 남습니다. 글자가 빠진 항목은 마우스를 올리면 이름이 뜹니다.
  • 캡처 방식 버튼에 아이콘이 붙었습니다.
  • 프로그램 파일을 찾지 못할 때 무엇을 해야 하는지 알려줍니다. (예전에는 파일 경로만 보여줬습니다) 백신이 프로그램 파일을 격리한 경우에 이 안내를 보게 됩니다.
  • 설치 프로그램이 파일이 실제로 복사됐는지 확인한 뒤 마무리합니다.

v1.9.5 2026-08-13

  • 설치 안내 페이지가 생겼습니다. 설치 방법, 단축키, 기능이 한 페이지에 정리돼 있고 판이 바뀌어도 주소는 그대로입니다. 지인에게 링크를 다시 보낼 필요가 없습니다.
  • 설정 창 [정보] 탭의 받는 곳 버튼이 이 안내 페이지를 엽니다.
  • 안내 페이지에 실제 프로그램 화면을 넣었습니다. 받기 전에 무엇이 열리는지 먼저 보실 수 있습니다.
  • 지금 보고 있는 변경 내용 페이지가 생겼습니다.

v1.9.4 2026-08-13

  • 설정 창에 [정보] 탭이 생겼습니다. 지금 판 번호를 보고 [업데이트 확인]으로 새 판이 있는지 알 수 있습니다. 누를 때만 인터넷에 연결하고, 보내는 정보는 없습니다.
  • 창을 좁히면 편집 창 아래 [변경] 버튼이 화면 밖으로 밀려나던 문제를 고쳤습니다.
  • 받는 파일에서 개발용 파일을 빼고, 설명서 이름을 사용설명서.md로 바꿨습니다.

v1.9.1 ~ v1.9.3 2026-08-13

  • 사용 조건(LICENSE.txt)을 넣었습니다. 개인·업무 용도로 자유롭게 쓰실 수 있고, 캡처한 결과물에 대한 권리는 전적으로 사용자에게 있습니다. 재배포와 판매는 허용되지 않습니다.
  • 프로그램 이름을 원스텝캡쳐로 통일했습니다. 예전 판에서 해둔 설정과 자동 실행은 그대로 유지됩니다.

v1.9.0 2026-08-13

  • 기본 단축키가 Alt + 1 ~ 4 로 바뀌었습니다. (1 영역 · 2 전체 화면 · 3 활성 창 · 4 스크롤) 이미 쓰던 분의 설정은 그대로 유지됩니다. 새 기본값을 쓰려면 설정 창에서 [전체 기본값으로]를 누르시면 됩니다.
  • Ctrl 이나 Shift 를 함께 누른 Print Screen이 단축키 칸에 입력되지 않던 문제를 고쳤습니다.
  • 저장과 관련된 설정을 모두 [저장] 탭 한곳에 모았습니다.

v1.8.1 2026-08-13

  • 확대경이 기본 꺼짐이 됐습니다. 늘 켜져 있으면 시야를 가려서, 설정 창 [동작] 탭에서 켜거나 영역을 고르는 중 Z 키로 그 자리에서 켜고 끌 수 있습니다.
  • 단축키 설정 화면을 다시 만들었습니다. 한 줄에 이름 · 키 · 되돌리기가 놓이고, 키 칸을 누른 뒤 원하는 키를 누르면 바로 바뀝니다.
  • Print Screen 을 단독으로 지정하면 동작하지 않습니다. Windows 가 그 키를 먼저 가져가기 때문입니다. 이제 안내 창이 떠서 바로 되는 대안(Shift 나 Ctrl 을 함께 누르는 방법)을 알려줍니다. PC 설정을 직접 바꾸지는 않습니다.

v1.8.0 2026-08-13

  • 조합키 없는 단축키를 쓸 수 있습니다. Print Screen · F1~F12 · Insert · Pause · Scroll Lock. 글자·숫자 키는 단독으로 쓸 수 없습니다 — 허용하면 그 키를 어디서도 입력할 수 없게 되기 때문입니다.
  • 영역을 고르는 화면이 정돈됐습니다. 모서리 손잡이 8개, 두 줄로 나뉜 크기 표시, 커서 주변을 7배로 보여주는 확대경, 빠른 실행 막대 아이콘. 화면이 좁아 막대가 잘려 양쪽 항목을 누를 수 없던 문제도 함께 고쳤습니다.
  • 설정 창이 왼쪽 탭으로 나뉘었습니다. 창 높이가 크게 줄어 한 화면에 편하게 들어옵니다.

v1.7.0 ~ v1.7.1 2026-08-13

  • 색과 굵기를 클릭 한 번으로 고릅니다. 색 견본 7칸과 굵기 4칸이 도구모음에 바로 놓여 있습니다. 마지막 + 칸에서 원하는 색을 직접 고를 수도 있습니다.
  • 글자 도구를 고르면 굵기 칸이 글자 크기로 바뀌고, 모자이크를 고르면 색 견본이 꺼집니다.
  • 편집 창 도구모음에 아이콘이 붙었습니다. 글자만 늘어서 있던 줄이 훨씬 읽기 쉬워졌습니다.
  • [복사] 이름을 [편집본 복사]로 바꿨습니다. 그려 넣은 표시까지 함께 복사되는 것이라 이름을 분명히 했습니다.

v1.6.0 ~ v1.6.1 2026-08-07 · 08-13

  • 편집 화면 확대 / 축소가 생겼습니다. Ctrl + 마우스 휠로 커서가 가리키는 지점을 제자리에 두고 10% ~ 800% 까지 조절합니다. 확대한 상태에서 휠이나 마우스 가운데 버튼 끌기로 화면을 옮길 수 있습니다.
  • 배율은 보는 배율일 뿐이라 저장·복사되는 이미지는 항상 원본 크기입니다.
  • 창을 좁히면 편집 창 아래 저장 폴더 항목이 사라지던 문제를 고쳤습니다.

v1.5.0 ~ v1.5.3 2026-08-07

  • 채팅창에서 스크롤 캡처가 안 되던 문제를 고쳤습니다. 채팅창은 대개 이미 맨 아래를 보고 있어 아래로 굴러가지 않습니다. 이제 위로 방향을 바꿔 지난 내용을 담습니다.
  • 설정 창이나 편집 창에서 활성 창 캡처를 누르면 모니터 전체가 찍히던 문제를 고쳤습니다.
  • 캡처 목록에서 Shift / Ctrl 여러 개 선택이 풀리던 문제를 고쳤습니다.
  • 써둔 글자를 끌어서 옮길 수 있습니다.
  • 설치 후 압축을 푼 폴더가 "사용 중입니다"로 지워지지 않던 문제를 고쳤습니다.
  • 저장 폴더를 바꾸는 [변경] 버튼을 저장 버튼 옆에 따로 뒀습니다.
  • 메모리 사용이 크게 줄었습니다. 전체 화면 5회 캡처 기준 108MB → 32MB, 창을 닫고 트레이에 있을 때는 1MB 미만입니다.
  • 자동 실행 방식을 시작프로그램 폴더로 바꾸고 설치 파일에서 알아보기 어려운 부분을 없앴습니다. 하는 일은 같지만 백신이 덜 예민하게 봅니다.

v1.4.0 2026-08-06

  • 스크롤 캡처가 한 화면만 찍히거나, 중간 내용이 빠지거나 겹치던 문제들을 고쳤습니다.
  • 영역을 고를 때 드래그 없이 클릭하면 커서 아래 창 전체를 잡습니다.
  • 캡처 목록 여러 개 선택, 선택 저장 · 선택 삭제 · 전체 삭제.
  • 파워셸 창을 닫으면 프로그램이 함께 꺼지던 문제, 편집 창이 항상 다른 창 위에 뜨던 문제를 고쳤습니다.
  • Windows 설정 > 앱 목록에서 제거할 수 있습니다.

v1.0.0 ~ v1.3.0 2026-07-31 · 08-05

  • 첫 판 — 영역 · 전체 화면 · 활성 창 캡처, 편집기, 트레이 상주.
  • 스크롤 캡처, 글자 넣기, 캡처 기록과 전체 저장, 단축키 사용자 설정.
  • 편집 창을 하나만 쓰면서 캡처별로 그려둔 표시를 보존합니다. 캡처 목록을 썸네일과 클릭 한 번 전환으로 바꿨고, 어두운 테마를 적용했습니다.
  • 설치가 끝나면 설정 창이 뜨고, 압축을 풀지 않고 실행하면 안내 창을 띄웁니다.
